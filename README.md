# Spec-Driven Development Workshop

This repository is created as part of the Vibe Coding / Coding with LLMs workshop to compare and contrast:
1. **Vibe Coding**: Rapid, conversational, iterative prototyping without formal specifications (built on the `vibe-coding` branch).
2. **Spec-Driven Development (SDD)**: Predictable, specification-first development using the [OpenSpec](https://openspec.dev) framework (built on the `sdd` branch).

## Project: Simple Notes App
The goal is to build the same Simple Notes App on both branches using their respective approaches to highlight the differences in code quality, predictability, regression risk, and development velocity.
