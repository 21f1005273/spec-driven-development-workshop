## Why

This change implements the Spec-Driven Development (SDD) version of the Simple Notes App. It is created to satisfy the workshop requirements and demonstrate a structured, spec-first methodology using OpenSpec on the `sdd` branch.

## What Changes

Create a modern, elegant, self-contained single-page web application featuring:
* Note creation, editing, and deletion.
* Real-time search across titles and note contents.
* Categorization using five distinct color-coded tags.
* Data persistence using browser localStorage.
* Modern responsive design with micro-animations.

## Capabilities

### New Capabilities
- `notes-management`: Capability to create, read, update, delete, search, and categorize notes with local storage persistence.

### Modified Capabilities

## Impact

* A new `index.html` will be created in the repository root.
* The `openspec/` directory will contain the living specifications and change proposals.
